# AGENTS.md

This repository is a design-system skill. When asked to build or restyle a UI "in Halo", or a bilingual English/Kurdish (RTL) interface, or an Apple-Fitness-like dashboard, read and follow [`SKILL.md`](SKILL.md) first. It holds the workflow, rules and the map to every doc.

Key rules: write the brief and design per product (docs/00-creative-direction.md; rings and the example's content are not defaults); platform → Halo → proven library (never invent mechanisms); no logos; tokens are the only source of colour and easing; design and test both themes, both directions and every breakpoint; run `qa/qa_layout.py` and `qa/qa_touch.py` before finishing.
