# 13 · QA protocol: try to break it

A Halo page ships only after a scripted QA run passes. The reference app passed 606 interaction checks plus phone-touch, layout and clipping suites. The scripts in [`qa/`](../qa) are the generic versions.

## The matrix
| Axis | Values |
|---|---|
| Width | 320 · 360 · 390 · 430 · 720 · 800 · 1024 · 1280 · 1440 |
| Theme | dark · light |
| Language | en (LTR) · ckb (RTL) |
| Input | mouse · touch (`hasTouch`, `isMobile`) |
| Motion | normal · `reducedMotion: 'reduce'` |

## Suites
1. **Layout** (`qa/qa_layout.py`): for every cell of the matrix,
   - no horizontal overflow (`scrollWidth <= innerWidth`);
   - no clipped text: any element with `white-space: nowrap` whose `scrollWidth` exceeds its box, and any heading, chip, button or label that overflows;
   - no console errors or page errors.
2. **Interaction** (write per product; see the reference checklist below). Click everything, type wrong values, reload, undo.
3. **Touch** (`qa/qa_touch.py`): tap glint appears and fades, the sheet swipes both ways (RTL-aware), the menu opens by tap and jumps to a section, every section reveals while scrolling, the pill stays on screen.
4. **Accessibility**: axe-core, see [12](12-accessibility.md).
5. **Visual review**: full-page screenshots of each section at 390 and 1440 in both themes, reviewed by eye for holes, collisions and imbalance ([04](04-layout.md) laptop audit).

## Reference interaction checklist
Steal these; they are the ones that found real bugs.
- Steppers: +, −, floor at 0, typed value, negative value clamps, huge value clamps.
- Theme toggles and persists across reload.
- Language toggles; the open dialog re-renders in place; scroll position is kept.
- Ticking an item starts the timer pill; +15, −15, pause holds, resume runs, skip hides.
- The timer pill is clickable **while a modal sheet is open** (it must live inside the dialog).
- The menu opens, Esc closes it, a link closes it **and** scrolls to the section (allow ~1.8 s for smooth scroll on long pages).
- The GitHub or identity link is present in both the nav and the menu.
- State persists after reload; reset and undo restore exactly.
- No JS errors at the end of the run.

## Testing tips
- Serve over `http://`, not `file://`. Storage and font loading behave differently on `file://` and produce false failures.
- Fonts from Google are often blocked in CI. Route `fonts.googleapis.com` to a local stylesheet pointing at `fonts/` so layout checks use the real metrics.
- If an element is off-screen, Playwright's touch tap hits nothing. Scroll it to the centre first.
- After animations, wait for transitions (`~1.2 s` after scrolling into view) before asserting opacity.
